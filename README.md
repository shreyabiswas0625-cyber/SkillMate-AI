# 🤖 SkillMate AI

SkillMate AI is an AI-powered Resume Reviewer built with **Python**, **Streamlit**, and the **Google Gemini API**. It analyzes uploaded resumes and provides detailed, actionable feedback to help users improve their chances of landing interviews.

---

## ✨ Features

- Upload resumes in PDF/TXT format
- AI-powered resume analysis using Google Gemini
- Download AI-generated resume analysis as a PDF report
- Comprehensive evaluation across:

  - Overall Resume Score (out of 100)
  - ATS Compatibility
  - Content Clarity
  - Skills Presentation
  - Experience Descriptions
  - Grammar & Formatting
  - Missing Skills
  - Strengths & Weaknesses
  - Personalized Suggestions for Improvement
 
    ---

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **Google Gemini API**
- **PyPDF2**
- **python-dotenv**

## Installation

```bash
git clone https://github.com/shreyabiswas0625-cyber/SkillMate-AI.git
cd SkillMate-AI
pip install -r requirements.txt
```

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key_here
```

Run the application:

```bash
streamlit run main.py
```
